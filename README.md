# ながのCAKE

長野県にある小さな洋菓子店「ながのCAKE」の商品を、全国のお客様に通販でお届けするためのECサイトです。  
Instagram を通じて人気となり、全国から注文が集まるようになったため、  
管理機能を含む便利な通販管理サイトを構築しました。

---

## 開発背景
これまでは Instagram のDMやメールで注文を受けていましたが、
注文内容の管理や顧客情報の管理が煩雑になっていました。  
そこで、注文管理・顧客管理・製作状況管理をまとめられるサイトが必要となり、開発に至りました。

---

## 目的
- 顧客がオンラインで商品を注文できる環境を整える
- 店舗側が注文内容や製作状況を一括管理できるようにする
- ECとして最低限必要な機能を実装し、実利用できるクオリティを目指す

---

---

## 会員側機能
- 会員登録、ログイン、ログアウト、退会
- 商品一覧、詳細表示
- カート追加、個数編集、削除
- 配送先の追加・編集・削除・複数登録
- 注文確定、注文履歴一覧、注文履歴詳細表示
- 金額計算（商品+送料）
- お届け先選択 / 支払い方法選択（クレジットカード／銀行振込）
- マイページ（登録情報編集）

---

## 管理者側機能
- 管理者ログイン
- 商品の新規登録 / 編集 / 削除 / 詳細
- 商品ステータス変更（販売中／販売停止中）
- 注文履歴一覧 / 詳細
- 注文ステータス更新（入金待ち／入金確認／製作中／発送準備中／発送済み）
- 顧客情報の閲覧・編集・退会処理

---

## 注文フロー（会員）
1. 商品を検索/閲覧
2. カートに追加
3. 注文情報入力（配送先・支払方法）
4. 注文確認
5. 注文確定 → サンクスページへ遷移
6. マイページから注文履歴閲覧可能

---

## 店舗側フロー
1. 注文内容を確認
2. 製作ステータスを更新
3. 発送手配
4. 発送完了ステータスに更新

---

## チーム体制
- 3名チーム開発 / GitHubフロー
- 週次KPT・振り返りで改善を続けながら作成
